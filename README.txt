CMU SafeWalk landing page

FILES
- index.html: complete responsive website prototype.

HOW TO PREVIEW
1. Extract the ZIP (if using the ZIP).
2. Double-click index.html to open it in your browser.

IMPORTANT ABOUT COUNTS
The built-in visit and support-click counters are local to each browser/device. They are useful for demonstrating the interaction, but they do not combine results from different visitors. For a real one-day validation test, publish the page and use a shared analytics setup or direct the support button to a Google Form so responses can be counted centrally.

PUBLISHING
You can upload index.html to a static hosting service, or recreate the design in Google Sites/Canva. A static host that supports uploading a single HTML file can publish this prototype. The page is not published online automatically by this file.
